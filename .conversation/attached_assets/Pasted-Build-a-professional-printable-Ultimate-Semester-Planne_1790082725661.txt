Build a professional, printable "Ultimate Semester Planner" web application for college and university students.

IMPORTANT:
- This should be a polished, production-quality product that could eventually be sold as a digital planner.
- Use only free/open-source libraries and assets.
- Do not use copyrighted images, logos, or paid assets.
- Make the design original.
- The application must work fully without requiring a backend.
- Make it responsive for desktop, tablet, and mobile.
- Use localStorage so user-entered information is saved in the browser.
- Add a Print / Export to PDF button using browser print functionality.
- The planner should be designed primarily for A4 printing.

TECH STACK:
- React
- TypeScript
- Tailwind CSS
- Lucide React icons
- No unnecessary dependencies
- Clean component-based architecture

DESIGN:
Create a modern, minimal, premium student-planner aesthetic.
Use lots of white space, soft rounded cards, subtle shadows, clean typography, and a professional academic appearance.
Use a soft lavender/blue accent palette but keep the pages printer-friendly.
Avoid an overly childish design.
The final product should look like something that could realistically be sold as a $3–$10 digital planner.

"Ultimate Semester Planner"

18. PRINTABLE PLANNER MODE
This is VERY IMPORTANT.

Create a dedicated "Print Planner" mode.

The printed pages must:

- Have clean margins

- Avoid dark backgrounds
- Use printer-friendly colors
- Keep tables inside page boundaries
- Avoid cutting content between pages where possible
